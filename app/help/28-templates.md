# Templates

Save a task you do again and again, then add a fresh copy with two clicks.

## How it works

**Save one.** Click the **☰** on any task and choose **Save as template**. Give it a name (the task's title is filled in for you) and press Enter.

A template keeps the task's title, description, estimate, impact and effort, and every step nested under it. It leaves out the deadline, start time and whether anything was done, so each copy starts fresh.

**Use one.** Click **📋 Templates** next to the add box and pick a template. A new copy, steps and all, lands in the project you are on.

**Delete one.** Click the **✕** beside it in the 📋 Templates list. Tasks you already made from it stay.

A template is its own saved copy, so editing or deleting the original task later does not change it.

## Why it works this way

Some jobs come back without a schedule: packing for a trip, onboarding someone, a deep clean. Rebuilding the same list of steps from memory each time is effort spent before the work even starts. If a job comes back on a fixed rhythm, a [repeating task](19-repeating-tasks.md) does this for you instead.
