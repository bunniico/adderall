# Magic ToDo: breaking tasks down

Turn a task you cannot start into steps you can.

## How it works

Open a task and press **⚡ Break down**. The AI writes a list of concrete subtasks and nests them under it. The **🌶** granularity slider (next to the add box, with a default in ⚙ Settings) controls how fine the steps are: 1 is broad, 5 is tiny.

Any subtask can be broken down again, as deep as you like.

If you already know a step, the **+** on any task adds a subtask by hand, at any depth. The box stays open after each one so you can type several in a row.

The task's **description** is passed to the AI, so anything specific about your situation ("I don't have a car") shapes the steps it writes.

## Why it works this way

A task like "sort out taxes" is hard to start because the first step is invisible. Breaking it down makes the first step visible, and the granularity slider exists because how small a step needs to be changes from day to day.

Breakdown uses a mid-sized model with a little thinking, because it is interactive: you are waiting for it. See [AI and your budget](23-ai-and-your-budget.md).

Steps stay in the order the breakdown gave them, whichever way the list is [sorted](10-sorting-and-ordering.md), because a plan's order is part of the plan.
